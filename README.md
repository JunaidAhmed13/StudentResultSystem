# Student Result Processing System
**Computer Organization & Assembly Language Lab — CEL 323**
Bahria University | BS-CS 4-B | Spring 2026

---

## What it does

A menu-driven console application written in x86 MASM Assembly that manages student records for a university department. Built using the Irvine32 library on Visual Studio.

- Add up to 5 students (name, roll number, marks for 5 subjects)
- View all records with totals, percentages, and pass/fail
- Search a student by roll number
- Sort students by total marks (descending)
- View a compact result summary

Pass criteria: percentage >= 40%

---

## Tools

- MASM (Microsoft Macro Assembler)
- Irvine32 Library
- Visual Studio 2022 (x86)

---

## How to run

1. Open Visual Studio
2. Create a new MASM project (x86)
3. Copy `main.asm` into the project
4. Make sure Irvine32 is linked (`C:\Irvine` path configured)
5. Build and run (Ctrl+F5)
